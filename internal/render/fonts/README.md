# Bundled fonts

| File | Font | License | Source |
|---|---|---|---|
| `LibreBaskerville-Bold.ttf` | Libre Baskerville Bold | SIL Open Font License 1.1 (`LibreBaskerville-OFL.txt`) | https://github.com/impallari/Libre-Baskerville (`fonts/ttf/`) |

The sans-serif and monospace frame fonts are the Go fonts from
`golang.org/x/image/font/gofont` (BSD-style license), so they need no files here.

The OFL allows bundling the font with software; the license file must stay next to it.
